# Історія і географія БЕЗ МЕЖ — V4

Це оновлена версія порталу на основі попереднього робочого архіву.

## Що змінено
- прибрані glow/pulse/надмірні тіні та розмиття;
- новий чистий стиль головного банера;
- єдина система кнопок, карток і типографіки;
- читабельний блок «Методична скарбничка» та поетичний блок;
- кнопка «↑» на довгих сторінках;
- футер на всіх сторінках містить «Вчитель Дмитрушківського ліцею»;
- особистий кабінет центрований і має зрозумілі можливості для учня та вчителя;
- роль користувача кешується локально, тому після входу більше немає постійного напису «Перевірка ролі…»;
- для власника порталу UID `LGw3zPR7w4SdN8zvi4LWExYTfFh2` роль автоматично фіксується як `teacher`;
- домашнє завдання має назву, предмет, клас, умову, дедлайн і матеріал;
- учень може здати текст і файл;
- учитель бачить роботи та може виставити оцінку і коментар;
- матеріали можна додавати URL або файлом через Firebase Storage;
- збережені НМТ/історичні/географічні матеріали залишені в комплекті.

## GitHub Pages
Завантажте в репозиторій файли з цього архіву та увімкніть Pages з гілки/папки, яку використовує ваш репозиторій.

## Firebase
Файл `database.rules.json` містить правила для Realtime Database. Його потрібно застосувати у Firebase Console або через Firebase CLI.

Файл `storage.rules` містить правила Firebase Storage.

> Важливо: для Google Sign-In домен GitHub Pages має бути доданий у Firebase Authentication → Authorized domains.
