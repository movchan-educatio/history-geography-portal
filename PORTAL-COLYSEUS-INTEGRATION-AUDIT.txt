WHAT CHANGED
1. The visible PLAY action no longer opens the old Firebase room system.
2. PLAY opens the working Colyseus game in a full-screen iframe overlay.
3. Existing Firebase code remains in the file for compatibility, but it is no longer the live multiplayer path.
4. Portal Google/Firebase remains for:
   - login;
   - activity leaderboard;
   - online presence;
   - Escape Room;
   - Portal Coins;
   - weekly winner;
   - other portal activities.
5. Player display name and selected portal hero are passed into Colyseus.
6. Colyseus sends match result back to the portal with postMessage.
7. Parent verifies the exact Render origin.
8. Portal Coins use the existing awardClashMatchReward(matchKey, place, score).
9. Local Clash wins/matches/best score are updated for the portal card.
10. A visible PORTAL button closes the iframe and returns to the portal.
