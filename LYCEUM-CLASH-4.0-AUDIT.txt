LYCEUM CLASH 4.0 — MVP REALTIME 3 PLAYERS

ДОДАНО
• Новий окремий режим LYCEUM CLASH, не видаляє «Вижити до дзвінка».
• До 3 авторизованих учнів у одній Firebase Realtime Database кімнаті.
• Створення кімнати + 5-символьний код + приєднання з іншого телефону.
• HOST запускає матч; для тесту дозволено стартувати навіть одному.
• 90-секундний режим «Битва за дзвінок».
• Віртуальний джойстик руху.
• Кнопка ВОГОНЬ з auto-aim до найближчого суперника.
• Ривок із 7-секундним cooldown.
• HP, знешкодження, респавн та коротка невразливість після повернення.
• Центральна зона дзвінка: +1 очко щосекунди.
• Знешкодження суперника: +5 очок.
• Realtime scoreboard для всіх учасників.
• Після 90 секунд — екран результатів і переможець.
• onDisconnect прибирає гравця при закритті вкладки.
• Якщо HOST виходить — HOST переходить наступному учаснику.
• Візуально окрема шкільна top-down арена з партами, локерами, центральним дзвінком, енергетичними пострілами.

ВАЖЛИВО
• Це перша realtime-версія. Firebase RTDB підходить для 3 учнів і коротких матчів, але не є спеціалізованим ігровим сервером.
• Синхронізація позицій ~12 разів/с. На хорошому Wi‑Fi/4G має бути придатно для шкільного міні-матчу; у наступних версіях можна додати interpolation/prediction і окремий сервер.
• Постійних Portal Coins за цей режим поки не нараховуємо, щоб не створити спосіб накрутки.

ПЕРЕВІРКА
• portal-score_4_0.js пройшов node --check.
• Усі inline JavaScript блоки index_4_0.html пройшли node --check.

HOTFIX ПЕРЕД ВИДАЧЕЮ
• Lobby/game/result display не конфліктують із inline display.
• Часті position-sync більше не можуть перезаписати HP або score.
• Очки зони додаються Firebase-транзакцією.
• HOST може повернути завершену кімнату у lobby і запустити реванш.
