# Історія і географія БЕЗ МЕЖ — фінальна версія

- Прибрано сторінку «Мій кабінет» і посилання на неї.
- Збережено поточний дизайн.
- Рейтинг працює через Firebase Realtime Database та оновлюється в реальному часі.
- Бали: історія, географія, НМТ і «Правда чи Брехня».
- НМТ синхронізує результати з Firebase.
- Чат синхронізується через Firebase.
- Наприкінці тижня переможцю записується бонус +2 у `weeklyWinners` та `weekly_bonus`.
- Вчитель визначається за UID порталу, учні — усі інші Google-акаунти.
